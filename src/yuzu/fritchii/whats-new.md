# Yngchii-X3D v5.6 (Ryzen 3D V-Cache Edition)

## ⚡ What's New in v5.6:
- **Upstream Sync**: Fully synchronized with Upstream v5.6 base engine & stability patches.
- **Dedicated GPU Thread Core Pinning**: GPUFront and GPUBack pinned to dedicated physical cores on the 3D V-Cache CCD while isolating Guest CPU threads.
- **120,461 Shader Buffer Fast-Path**: Eliminates runtime shader compilation stutter.
- **Hardware CPU Gate**: Auto-detects AMD Zen 3 / Zen 4 / Zen 5 (Ryzen 5 / 7 / 9) and auto-tunes high-resolution kernel timer (0.5ms).
- **Bilingual EN / VN Interface**: Dynamic vertical switch on the sidebar for instant English and Vietnamese localization.
- **Discord Rich Presence**: Native Win32 named-pipe status integration with Pochita artwork.
- **Optimized Presets**: Automatically applies verified performance configurations for Zelda: Ocarina of Time and Tears of the Kingdom.
- **In-App Updater Redirection**: Direct GitHub release updates from yngvifreyr1810/Yngchii-X3D.
